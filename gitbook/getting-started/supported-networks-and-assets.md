# Supported Networks & Assets

Heres Protocol continuously expands its supported asset classes to support the diversification of your portfolio. Below are the currently supported networks and digital tokens, along with upcoming real-world assets (RWAs) and NFTs.

### **Supported Networks**&#x20;

| Network                  | Environment      | Status        | Description                                                                                 |
| ------------------------ | ---------------- | ------------- | ------------------------------------------------------------------------------------------- |
| **Solana (SOL)**         | Mainnet          | `Coming Soon` | The base layer of Heres Protocol, offering ultra-fast and low-cost contract execution.      |
| **Solana (SOL)**         | Devnet / Testnet | `Live`        | Test environments for trying out new features and developer integrations.                   |
| **Ethereum (ETH)**       | Testnet          | `Coming Soon` | Ethereum mainnet asset bridging via CCTP (Cross-Chain Transfer Protocol).                   |
| **Stellar Lumens (XLM)** | Testnet          | `Coming Soon` | Integration of Stellar's fast, low-cost cross-border transfer infrastructure.               |
| **ARC Network**          | Testnet          | `Coming Soon` | Cross-chain asset integration and inheritance infrastructure support for the ARC ecosystem. |

### **Supported Digital Tokens**

| Asset       | Category            | Description                                                                                         |
| ----------- | ------------------- | --------------------------------------------------------------------------------------------------- |
| **SOL**     | Native Asset        | The primary currency of the Solana ecosystem.                                                       |
| **ETH**     | Native Asset        | Ethereum-based bridging assets (e.g., WETH).                                                        |
| **BTC**     | Native Asset        | Bitcoin wrapped assets (e.g., WBTC, tBTC).                                                          |
| **USDC**    | Stablecoin          | Fiat-pegged stablecoin to hedge against market volatility risks.                                    |
| **USDT**    | Stablecoin          | Tether-based stablecoin.                                                                            |
| **JitoSOL** | Yield-bearing (LST) | Liquid Staking Token that continuously accrues staking and MEV rewards while stored in the Capsule. |
| **mSOL**    | Yield-bearing (LST) | Marinade Finance's Liquid Staking Token.                                                            |
